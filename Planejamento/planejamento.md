# 🐧 Planejamento do Projeto PinguInvest

## 1. Visão Geral

O PinguInvest é uma plataforma web criada para auxiliar usuários no gerenciamento de investimentos e no desenvolvimento da educação financeira.

O sistema busca fornecer uma experiência simples e intuitiva para acompanhamento patrimonial, registro de movimentações e consulta de conteúdos educativos.

---

## 2. Problema

Muitos investidores utilizam planilhas complexas ou múltiplas plataformas para acompanhar seus investimentos.

Isso gera dificuldades como:

- Falta de organização;
- Controle financeiro fragmentado;
- Dificuldade de acompanhamento patrimonial;
- Pouco acesso a conteúdos educativos.

---

## 3. Solução Proposta

O PinguInvest centraliza informações financeiras em uma única plataforma.

O sistema permitirá:

- Controle da carteira;
- Registro de movimentações;
- Acompanhamento patrimonial;
- Acesso a conteúdos educacionais.

---

## 4. Objetivos

### Objetivo Geral

Desenvolver uma plataforma web para gerenciamento de investimentos.

### Objetivos Específicos

- Implementar autenticação de usuários;
- Desenvolver dashboard financeiro;
- Criar sistema de controle patrimonial;
- Implementar histórico de movimentações;
- Disponibilizar conteúdos educativos.
